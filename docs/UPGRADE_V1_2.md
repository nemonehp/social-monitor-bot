# Обновление до v1.2.0

## Что меняется

- Уведомления получают единый заголовок `✈️/🟦 · ПОСТ/ИСТОРИЯ · дата МСК`.
- Доставка выполняется одним последовательным потоком: публикации одной группы отправляются пакетом и по времени выхода, без перемешивания с другой группой.
- Медиа остаются только превью; видео, аудио и документы целиком не скачиваются. После успешной доставки локальные превью удаляются.
- Добавляется содержательная проверка Telegram-сессий и VK-токенов на каждой проверке источника.
- Отозванные токены/сессии получают статус `dead`, исключаются из пула и не восстанавливаются автоматически. Лимиты получают `cooldown/limited`.
- Прокси молча уходят в карантин; если ни одной успешной проверки не было три часа, прокси получает статус `removed`.
- При количестве рабочих VK-прокси ниже половины VK-аккаунтов отправляется редкий аварийный алерт.
- Положительные сообщения о восстановлении отключены. Сохраняются только существенные отрицательные события.
- Раз в сутки после 00:00 МСК отправляется статистика за предыдущий московский день.
- Федеральный округ и регион переносятся в универсальные `Категория` и `Подкатегория`.
- Docker использует один общий образ приложения, а логи каждого контейнера ограничены 3 × 10 МБ.

## Миграция

Миграция `0003_unified_delivery_health_categories` не удаляет источники, публикации, доставки, аккаунты, токены, Telegram-сессии или прокси. Она добавляет категории и поля состояния здоровья.

## Обновление production

```bash
cd /opt/social-monitor/app
CONFIRM_V1_2_UPGRADE=YES ./scripts/upgrade_v1_2.sh
```

Скрипт создаёт резервные копии PostgreSQL и действующего `.env` в `/opt/social-monitor/backups`, точечно выставляет согласованные параметры доставки/алертов/proxy lifecycle, останавливает прикладные сервисы, собирает единый образ, применяет миграцию и запускает контейнеры. Токены, пароли, ключ шифрования и Telegram-сессии не изменяются.

После обновления:

```bash
docker compose ps -a
docker compose exec -T postgres sh -lc \
  'psql -X -At -U "$POSTGRES_USER" -d "$POSTGRES_DB" -c "select version_num from alembic_version"'
docker compose logs --since=10m --tail=300 scheduler worker-tg worker-vk delivery bot
```

Ожидаемая ревизия: `0003_unified_delivery_health_categories`.
