# Обновление до v1.3.0

## Что меняется

- Новая миграция `0004_capacity_forum_integrity` добавляет учёт API-расхода, VK-привязки к прокси/IP и контроль полноты.
- Секреты, источники, checkpoint, публикации и история доставок не удаляются.
- Глобальный интервал больше нельзя уменьшить ниже рассчитанной безопасной мощности.
- При внезапной нехватке мощности новые проверки соответствующей платформы приостанавливаются, существующая очередь сохраняется, checkpoint не продвигается.
- Для VK действует максимум три активных аккаунта на один внешний IP. Telegram этим ограничением не связан.
- Для корректного определения шестичасового токена импортируйте полный OAuth-ответ или URL с `access_token` и `expires_in`, а не только голую строку токена.

## Сигнальный чат

Bot API не умеет преобразовывать обычную группу в супергруппу. Владелец должен преобразовать группу и включить режим «Темы». После повторного подключения бот проверит права управления темами и создаст:

- `🟢 VK · ПОСТЫ`
- `🟢 VK · ИСТОРИИ`
- `🔵 TG · ПОСТЫ`
- `🔵 TG · ИСТОРИИ`
- `🟡 СТАТИСТИКА`

При переключении на другой чат старые ID тем не переиспользуются.

## Безопасные значения по умолчанию

```env
ACCOUNT_DAILY_BUDGET_FRACTION=0.30
VK_OPERATIONAL_DAILY_REQUEST_BUDGET=100000
TG_OPERATIONAL_DAILY_REQUEST_BUDGET=250000
VK_ESTIMATED_REQUESTS_PER_SOURCE_CYCLE=2.25
TG_ESTIMATED_REQUESTS_PER_SOURCE_CYCLE=2.0
VK_MAX_ACCOUNTS_PER_IP=3
CAPACITY_GUARD_ENABLED=true
```

Операционные бюджеты — внутренние консервативные пределы, потому что платформы не публикуют один универсальный фиксированный дневной лимит для всех аккаунтов и методов. После реального rate-limit бюджет конкретного аккаунта временно уменьшается.

```bash
CONFIRM_V1_3_0_UPGRADE=YES ./scripts/upgrade_v1_3_0.sh
```
