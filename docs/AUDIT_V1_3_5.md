# Аудит v1.3.5

## Production-выборка

Экспорт снят с production v1.3.4 после реальных циклов VK, Telegram и доставки.

За последние 24 часа зафиксировано:

- 1373 успешных VK-цикла;
- 418 успешных Telegram-циклов;
- 1109 событий `collection_integrity_gap`;
- 322 Telegram retry;
- 15 доставок, из которых 11 имели несколько Telegram message ID.

Повторных `item_key` и повторных строк доставки не найдено.

## Найденные проблемы

### Ложные integrity gaps

Последний ID платформы сравнивался только с сохранёнными объектами и checkpoint. Коллектор мог увидеть новый закреплённый, исторический, служебный или неподдерживаемый объект и намеренно не сохранять его. Контроль считал это потерей, замораживал checkpoint и повторял задачу.

Исправление: коллекторы передают множества фактически увиденных post/story IDs. Наблюдаемый remote latest ID не считается пропущенным. Миграция сбрасывает накопленные ложные счётчики, но не меняет checkpoint.

### Telegram connection cascade

272 retry были вызваны использованием уже отключённого клиента, ещё 50 — `TypeNotFoundError`. После первой ошибки один и тот же клиент продолжал получать задачи. Текст `TypeNotFoundError` включал большой бинарный остаток пакета.

Исправление: worker завершает слот и пересоздаёт клиент после disconnected/декодирующей ошибки. Ошибки нормализуются и ограничиваются безопасным текстом без бинарных данных.

### Непоследовательная доставка

Старая проверка использовала длину сырого HTML и порог 950. Длинные URL внутри `<a href>` ошибочно считались частью caption, поэтому короткий видимый пост уходил отдельно от альбома.

Исправление: лимит считается по видимому тексту после HTML parsing в UTF-16 units. Полная карточка помещается в первый элемент альбома при возможности. Иначе текст всегда идёт первым, медиа отвечает на него. При media fallback текст не теряется и не повторяется.

## Риск данных

Изменения не удаляют источники, items, deliveries, очереди или checkpoint. Миграция меняет только состояние ложных integrity-сигналов. Отложенные задания выполняются обычным catch-up после обновления.
