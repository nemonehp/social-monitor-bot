# Обновление до v1.3.2

Hotfix устраняет падение доставки альбомов на aiogram 3/Pydantic 2:
`InputMediaPhoto` является неизменяемой моделью, поэтому подпись теперь передаётся при создании первого элемента media group.

Миграции базы данных нет. Застрявшие доставки остаются в статусе retry и после перезапуска отправляются автоматически.

```bash
CONFIRM_V1_3_2_UPGRADE=YES ./scripts/upgrade_v1_3_2.sh
```
