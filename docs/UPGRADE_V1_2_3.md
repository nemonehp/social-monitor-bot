# Обновление до v1.2.3

Версия устраняет обнаруженные в production дефекты доставки и превью без сброса источников, checkpoint, аккаунтов или настроек.

## Исправления

- Длинное сообщение с одним медиа больше не повторяет начало текста в подписи и затем целиком отдельным сообщением.
- Для VK-репостов одинаковые текст и вложения из внешнего поста и `copy_history` объединяются один раз.
- Telegram выбирает крупнейший обычный thumbnail или `video_cover`; крошечный размытый `PhotoStrippedSize` не отправляется.
- Изображения нормализуются в JPEG до 1600 px и 3 МБ. Полный файл изображения-документа скачивается только при известном размере до 12 МБ.
- Полные видео, аудио и обычные документы по-прежнему не скачиваются. Если Telegram не отдаёт нормальное превью, сигнал уходит без изображения.
- VK error 1116 считается окончательно мёртвым токеном и сразу исключается из пула; токены удаляются из сообщений ошибок.
- Доставка продлевает lease heartbeat-ом, а `attempts` увеличивается только перед фактической отправкой конкретного сообщения.

## Запуск

```bash
CONFIRM_V1_2_3_UPGRADE=YES ./scripts/upgrade_v1_2_3.sh
```

Скрипт:

1. проверяет Docker Compose и наличие минимум 2 ГиБ свободного места;
2. сохраняет действующий `.env`;
3. запускает PostgreSQL при необходимости и создаёт `pg_dump`;
4. останавливает прикладные сервисы;
5. собирает общий образ;
6. применяет ожидающие миграции;
7. запускает сервисы и проверяет Alembic revision;
8. при ошибке пытается снова поднять приложение.

Alembic revision остаётся `0003_unified_health_categories`: миграция базы для v1.2.3 не требуется.

## Проверка

```bash
docker compose ps -a

docker compose logs --since=10m --no-color \
  scheduler worker-tg worker-vk delivery bot \
  | grep -iE 'traceback|exception|error|failed' \
  || echo "Явных ошибок не найдено"
```

Проверить следует четыре случая: длинный репост с медиа, обычную фотографию, изображение как Telegram-документ и видео с доступным `video_cover`.
