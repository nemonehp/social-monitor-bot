# Обновление до v1.3.5

Релиз унифицирует компоновку сигналов, устраняет ложные integrity-gap циклы и восстанавливает Telegram-клиенты после повреждённого/разорванного соединения.

## Доставка

- полная карточка и медиа отправляются вместе, когда видимый текст помещается в Telegram caption;
- для альбома caption задаётся первому элементу;
- при превышении лимита сначала отправляется полный текст, затем медиа ответом;
- при ошибке вложений текст остаётся доставленным и получает предупреждение;
- количество message ID у альбома соответствует числу его элементов, но в Telegram они отображаются как единый альбом.

## Integrity

Миграция `0007_integrity_observation` сбрасывает накопленные ложноположительные gap-счётчики. Source checkpoint, публикации, истории и очередь не изменяются.

## Telegram worker

Disconnected и `TypeNotFoundError` завершают текущий клиентский слот, после чего supervisor создаёт новое соединение. Бинарный payload исключения не записывается в лог или БД.

## Запуск

```bash
CONFIRM_V1_3_5_UPGRADE=YES ./scripts/upgrade_v1_3_5.sh
```

Ожидаемая Alembic revision: `0007_integrity_observation`.
